# شبكة التشييد للمقاولات العامة

موقع وتطبيق شبكة التشييد للمقاولات العامة والنظافة والخدمات المنزلية - مكة المكرمة.

## التشغيل محلياً

```sh
npm install
npm run dev
```

## بناء المشروع

```sh
npm run build
```

## التقنيات المستخدمة

- TanStack Start
- React 19
- TypeScript
- Vite
- Bootstrap RTL Grid
